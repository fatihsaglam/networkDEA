# networkDEA 0.1.0

* First release.
* `ndea_two_stage()`: two-stage network DEA, flexible synergy (CRS/VRS, input/output
  orientation) and classical rigid synergy (CRS).
* `ndea()` with `node()` / `network()`: generalized network DEA for arbitrary
  serial/parallel node structures, with synergy-loss `D*` and node weights.
* Not yet available: reference sets and projections for the generalized model,
  FDEF-based models, classical (rigid) two-stage model under VRS.
